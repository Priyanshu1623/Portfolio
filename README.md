# 🌐 Personal Portfolio Website

## 🚀 Live Demo
**[🔴 Live Demo - Click Here](https://priyanshu1623.github.io/Portfolio/)**
Welcome to my personal portfolio repository! This website is designed to showcase my skills, projects, and professional journey as a Frontend Web Developer. It serves as a digital resume and a hub for everything I build.



---

## ✨ Features

- **About Me:** A brief introduction to who I am and my passion for web development.
- **Project Showcase:** A clean grid/list displaying my best works (like the Online MCQ Portal).
- **Interactive UI:** Smooth scrolling, elegant hover effects, and a modern layout.
- **Resume/CV Integration:** Direct access to my official resume (`Priyanshu.pdf`) directly from the site.
- **Fully Responsive:** Optimized perfectly for mobile, tablet, and desktop viewports.
- **Contact Form/Links:** Easy ways to connect with me via email or social platforms.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for a clean layout and SEO optimization.
- **CSS3:** Custom layouts, modern typography, transitions, and responsive media queries.
- **JavaScript (ES6):** Dynamic interactivity, DOM manipulations, and smooth animations.
